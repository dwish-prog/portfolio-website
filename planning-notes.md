## Project Scope
### Project Objectives from Codecademy
For this project, you will build a personal portfolio site, a static website where you can share the projects that you build in this Path. Typically, a portfolio website will have a main page that features different projects that you’ve built and another page that contains contact information, in case someone wants to reach out to you. Occasionally, there are additional pages for each project, detailing the technology used.
- Build a website using HTML, CSS
- Add at least one interactive feature using JavaScript
- Use Git version control
- Use the command line and file navigation
- Develop locally on your computer
- Deploy your site to the web using GitHub Pages
- OPTIONAL: Buy a custom domain name and have it point to your GitHub Pages website
### My Project Objectives
As well as the Codecademy objectives, I want to revise my learning from the *MDN Learn* course. I also want to combine my music website (created with Hostinger tools) with the project to reflect my desired online brand.
- Design a **responsive** website that reflects modern best design practices and my desired online brand.
- Avoid using AI, except as a troubleshooting tool alongside google.
- Collect notes about the process to update my web development quick reference.
- Allow switching between English and German.
